# Changelog

## v0.1.0 — 17 October 2026

First public beta. Still under development.

- Local excerpt capture from dropped text and explicit clipboard actions.
- Five reading companions, with optional movement and matching system icons.
- Editable excerpts, source details, and Markdown export.
- Book metadata and cover search, plus browser capture bookmark setup.
- Optional, explicitly confirmed publication to a Markdown website repository.

Known limitations include incomplete source detection, browser setup that needs more testing, development signing, and experimental website publication. See the README before using the publishing workflow.
